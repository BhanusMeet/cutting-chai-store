# Vintage Web and Cutting Chai

| Folder | What it is |
|---|---|
| [`qr-order/`](qr-order/README.md) | QR table-ordering store: guest menu, kitchen, counter, printing, stock, margins and Excel sheets. Python standard library only. |
| [`cutting-chai/`](cutting-chai/) | The static Cutting Chai website (plain HTML, CSS and JavaScript). |
| [`vintage-web-plugin/`](vintage-web-plugin/) | The `vintage-web` Claude Code skill for authentic vintage website styles. |
| `vintage-web-workspace/`, `vintage-web-review*.html` | Test runs and reviews of that skill. |

The ordering store needs a computer running its Python server, so it cannot run on GitHub Pages.
To run it, see [`qr-order/README.md`](qr-order/README.md).
